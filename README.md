# Spleef Remastered

Spleef Remastered is a Roblox competitive arena game where players survive by
breaking tiles, dodging attacks, and outlasting opponents in fast-paced rounds.

## Project Overview

This project is organized with:

- `src/Client` for player input, UI, camera, effects, and client gameplay logic
- `src/Server` for game systems, round flow, services, and server authority
- `src/Shared` for shared data, types, utilities, and remote contracts

It uses Argon for project syncing/build workflows.
